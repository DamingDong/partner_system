# React 开发技能

## 技能概述
为合作伙伴管理系统提供专业的 React 开发技能，基于协作框架实现组件开发、状态管理、路由配置等。

## 协作角色定位

### React 开发职责
- **前端实现者**：基于产品需求实现用户界面
- **用户体验优化者**：确保界面交互流畅和美观
- **组件库维护者**：构建和维护可复用组件
- **性能优化者**：优化前端性能和用户体验

### 协作接口定义
- **与产品经理**：确认界面需求和交互设计
- **与API集成团队**：协调数据格式和交互协议
- **与设计团队**：实现设计规范和用户体验
- **与AI助手**：自动化组件文档和代码质量检查

## 核心能力

### 1. 协作式组件开发
- 创建可复用的 React 组件，基于协作框架的需求确认
- 使用 TypeScript 进行类型安全开发，确保团队协作质量
- 实现响应式设计，满足多设备用户体验需求
- 遵循 Shadcn/ui 设计规范，保持界面一致性

### 2. 协作式状态管理
- 使用 Zustand 进行全局状态管理，支持跨组件协作
- 实现本地状态管理（useState, useReducer），确保组件独立性
- 服务端状态管理（React Query），与后端团队协作数据同步

### 3. 协作式路由管理
- React Router 配置，基于产品导航需求
- 权限路由控制，与权限管理团队协作
- 嵌套路由实现，支持复杂页面结构

### 4. 协作式表单处理
- React Hook Form 集成，确保表单数据一致性
- 表单验证和错误处理，支持业务规则验证
- 复杂表单状态管理，与产品经理确认交互逻辑

## 最佳实践

### 代码规范
- 使用 ESLint 和 Prettier
- 遵循 TypeScript 严格模式
- 组件命名规范（PascalCase）
- 文件组织规范

### 性能优化
- 组件懒加载
- 代码分割
- 内存泄漏预防
- 渲染性能优化

### 测试策略
- 单元测试（Vitest）
- 组件测试（React Testing Library）
- E2E 测试（Playwright）

## 项目特定要求

### 合作伙伴系统特性
- 多角色权限控制
- 数据表格和分页
- Excel 导出功能
- 实时数据更新

### UI/UX 要求
- 响应式设计支持
- 无障碍访问支持
- 国际化准备
