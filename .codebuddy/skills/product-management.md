# 产品经理技能

## 技能概述
为合作伙伴管理系统提供专业的产品管理技能，基于协作框架实现需求分析、文档编写、产品规划和跨职能协作。

## 协作角色定位

### 产品经理核心职责
- **需求定义者**：将业务需求转化为可执行的产品需求
- **项目协调者**：协调业务方、技术团队和AI助手的协作
- **质量保证者**：确保交付成果符合业务需求和用户体验
- **文档管理者**：维护产品文档的完整性和一致性

### 协作接口定义
- **与业务方**：需求收集、优先级确认、验收确认
- **与技术团队**：需求澄清、技术可行性评估、进度跟踪
- **与AI助手**：文档维护、技术分析、自动化协作

## 核心能力

### 1. 协作式需求文档体系
- **BRD (业务需求文档)**：高层业务目标和价值主张，与业务方协作定义
- **MRD (市场需求文档)**：市场分析、用户画像、竞争分析，基于协作框架
- **PRD (产品需求文档)**：详细功能规格，与技术团队协作确认技术可行性
- **EPIC (史诗级需求)**：大型功能模块分解，与AI助手协作确保文档对齐
- **用户故事库**：基于协作框架的用户故事定义和优先级管理

### 2. 协作式文档编写规范
- 结构化文档格式，支持自动化协作
- 清晰的用户故事描述，便于技术团队理解
- 完整的验收标准，支持AI助手自动化验证
- 优先级和版本管理，确保协作一致性

### 3. 协作式需求管理流程
- **需求收集**：通过协作框架标准化收集流程
- **优先级排序**：基于协作角色矩阵确定优先级
- **需求评审**：跨职能协作评审
- **变更管理**：协作框架下的变更控制
- **需求追溯**：AI助手支持的自动化追溯

#### 详细 PRD 示例
```markdown
# PRD: 订单管理功能增强

## 功能描述
在现有订单管理基础上，增加订单类型区分和分账规则应用。

## 用户故事
**作为合作伙伴，我希望能够区分激活订单和订阅订单，以便正确应用分账规则。**

### 验收标准
- [ ] 订单列表显示订单类型标识
- [ ] 激活订单不参与分账计算
- [ ] 订阅订单按照分账规则计算佣金
- [ ] 订单导出包含订单类型信息

## 详细需求

### 数据模型变更
```typescript
interface Order {
  id: string;
  orderType: 'ACTIVATION' | 'SUBSCRIPTION'; // 新增字段
  orderAmount: number;
  commissionAmount: number;
  // ... 其他字段
}
```

### 业务逻辑规则
- 激活订单：commissionAmount = 0
- 订阅订单：commissionAmount = orderAmount * commissionRate
- 订单列表需要按类型筛选
```

### 开发过程中的文档更新

## 文档更新流程

### 1. 需求变更识别
- 开发过程中发现的新需求
- 技术实现导致的逻辑调整
- 用户反馈的功能优化

### 2. 文档更新步骤
1. **识别变更点**：明确需要更新的文档部分
2. **评估影响**：分析变更对其他功能的影响
3. **更新文档**：在相关文档中记录变更
4. **通知相关方**：同步技术团队和业务方
5. **版本控制**：记录变更历史和版本号
