# EPIC: 平台方会员卡配置管理

## 🎯 Epic目标
支持平台方进行会员卡的导入、库存查看、权限配置和基础发放，为渠道合作伙伴提供基础数据支持和权限管理。

## 📋 业务价值
- **基础数据支持**：为渠道合作伙伴提供会员卡数据基础
- **权限配置管理**：灵活配置渠道合作伙伴的权限范围
- **全局库存管理**：监控和管理全局会员卡库存状态

## 🔧 核心功能

### 1. 会员卡导入功能
**功能描述**：支持平台方导入新的会员卡数据到系统
**验收标准**：
- Excel模板批量导入会员卡池（支持1000张/次）
- 会员卡数据格式校验和重复检查
- 导入失败错误报告和重试机制
- 导入操作历史记录

### 2. 会员卡库存查看功能
**功能描述**：支持平台方查看所有会员卡的库存和状态总览
**验收标准**：
- 查看所有会员卡库存状态监控和预警
- 按渠道、状态等多维度统计
- 库存趋势分析和关键指标展示
- 库存数据准确性验证

### 3. 渠道合作伙伴权限配置
**功能描述**：支持平台方配置渠道合作伙伴的权限范围
**验收标准**：
- 支持配置会员卡代理业务权限（绑定、回收、兑换）
- 支持配置订阅订单分账业务权限（订单查询、分账查看）
- 支持配置混合权限（同时具备两种业务权限）
- 权限配置界面直观易用，操作日志审计

### 4. 会员卡发放功能
**功能描述**：支持平台方为渠道合作伙伴分配/发放会员卡
**验收标准**：
- 支持单个和批量会员卡发放
- 发放记录和操作历史
- 发放数量配置和库存验证
- 发放通知和状态更新

## 🔄 权限配置管理

### 权限配置模式
平台方可以为每个渠道合作伙伴配置以下三种权限模式：

#### 模式1：仅会员卡代理业务权限
- 允许访问：会员卡绑定、回收、兑换功能
- 数据范围：自有会员卡和设备数据
- 适用对象：专注于会员卡代理业务的合作伙伴

#### 模式2：仅订阅订单分账业务权限
- 允许访问：订阅订单查询功能
- 数据范围：自有渠道的订阅订单数据
- 适用对象：专注于订阅分账业务的合作伙伴

#### 模式3：混合权限（两者兼具）
- 允许访问：所有会员卡业务和订阅订单功能
- 数据范围：完整的业务数据访问权限
- 适用对象：同时开展两种业务的合作伙伴

### 权限配置流程
1. **创建合作伙伴账号**：平台方创建新的渠道合作伙伴账号
2. **配置权限模式**：选择适合的权限配置模式
3. **分配会员卡**：为合作伙伴分配会员卡库存
4. **权限生效**：合作伙伴登录后只能访问配置的功能

### 与CHANNEL_PARTNER Epic的关联

- 平台方提供的会员卡数据是渠道合作伙伴业务的基础

```

                                     ↓
渠道合作伙伴登录 → 根据权限访问功能 → 开展业务活动
```
