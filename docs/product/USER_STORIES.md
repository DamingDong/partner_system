# 用户故事库 - 合作伙伴管理系统

## 📋 用户故事定义标准

### 用户故事模板
```
作为 [角色]
我想要 [功能]
以便于 [业务价值]
```

### 验收标准格式
- **Given** [前置条件]
- **When** [操作行为]
- **Then** [预期结果]

## 👥 用户角色定义

### 系统管理员 (Admin)
- 负责系统配置和全局管理
- 拥有最高权限级别

### 合作伙伴 (Partner)
- 系统的核心用户
- 管理自己的业务数据和分账

### 操作员 (Operator)
- 负责日常运营维护
- 有限的管理权限

## 📊 用户故事分类

### 1. 会员卡管理相关故事

#### US-001: 查看会员卡列表
**作为** 合作伙伴
**我想要** 查看我管理的会员卡列表
**以便于** 了解会员卡的整体状态

**验收标准**:
- Given 用户已登录且有会员卡管理权限
- When 用户访问会员卡列表页面
- Then 显示该合作伙伴的所有会员卡
- Then 支持按状态、类型、时间筛选
- Then 支持分页显示

#### US-002: 激活会员卡
**作为** 合作伙伴
**我想要** 激活待激活的会员卡
**以便于** 开始为会员提供服务

**验收标准**:
- Given 用户有会员卡激活权限
- When 用户选择待激活的会员卡并点击激活
- Then 系统验证会员卡状态为可激活
- Then 生成激活订单记录
- Then 更新会员卡状态为已激活

### 2. 订单管理相关故事

#### US-003: 查看订单详情
**作为** 合作伙伴
**我想要** 查看订单的详细信息
**以便于** 了解订单的处理状态和分账情况

**验收标准**:
- Given 用户有订单查看权限
- When 用户点击订单列表中的某个订单
- Then 显示订单的完整信息（订单号、金额、状态等）
- Then 显示分账计算明细（仅订阅订单）
- Then 显示订单处理历史记录

#### US-004: 导出订单数据
**作为** 合作伙伴
**我想要** 导出订单数据到Excel
**以便于** 进行离线分析和报表制作

**验收标准**:
- Given 用户有订单导出权限
- When 用户选择筛选条件并点击导出
- Then 系统生成Excel文件并下载
- Then 文件包含所有筛选条件下的订单数据
- Then 文件格式规范，包含表头和数据类型

### 3. 分账管理相关故事

#### US-005: 查看分账明细
**作为** 合作伙伴
**我想要** 查看每笔订单的分账明细
**以便于** 了解收入来源和分账比例

**验收标准**:
- Given 用户有分账查看权限
- When 用户查看订阅订单详情
- Then 显示分账规则类型（固定/阶梯/条件）
- Then 显示分账比例和计算过程
- Then 显示实际分账金额
- Then 激活订单明确标注"不参与分账"

#### US-006: 分账规则查询
**作为** 合作伙伴
**我想要** 查询适用的分账规则
**以便于** 了解不同业务场景下的分账政策

**验收标准**:
- Given 用户有规则查询权限
- When 用户查询分账规则
- Then 显示当前生效的分账规则
- Then 明确标注规则适用条件
- Then 提供规则生效时间和适用范围

### 4. 对账管理相关故事

#### US-007: 生成对账单
**作为** 合作伙伴
**我想要** 生成指定周期的对账单
**以便于** 进行财务核对和结算

**验收标准**:
- Given 用户有对账权限
- When 用户选择对账周期（日/周/月）
- Then 系统自动生成对账单PDF
- Then 对账单包含订单汇总和分账明细
- Then 支持下载和打印

#### US-008: 对账状态管理
**作为** 合作伙伴
**我想要** 标记对账单为已核对
**以便于** 跟踪对账进度

**验收标准**:
- Given 用户有对账管理权限
- When 用户完成对账核对
- Then 可以标记对账单为已核对状态
- Then 系统记录核对时间和操作人
- Then 已核对的对账单有明确标识

### 5. 数据报表相关故事

#### US-009: 查看业务报表
**作为** 合作伙伴

- Then 显示关键业务指标（收入、订单数、会员数等）

#### US-010: 自定义报表

**验收标准**:

- Then 支持保存自定义报表模板

### 6. 分账管理相关故事

#### US-013: 分账规则配置
**作为** 系统管理员
**我想要** 配置和管理分账规则
**以便于** 灵活调整不同业务场景下的分账政策

**验收标准**:
- Given 用户有分账规则配置权限
- When 用户创建新的分账规则
- Then 支持选择规则类型（固定/阶梯/条件）
- Then 可以设置规则优先级和适用条件
- Then 规则生效时间范围必须有效
- Then 规则变更需要审批流程
- Then 支持规则测试和预览功能

#### US-014: 分账异常处理
**作为** 系统管理员
**我想要** 处理分账计算异常
**以便于** 确保分账计算的准确性和完整性

**验收标准**:
- Given 用户有分账异常处理权限
- When 系统检测到分账计算异常
- Then 显示异常详情和错误原因
- Then 支持手动重算和自动重试
- Then 异常处理记录需要审计日志
- Then 重要异常需要通知相关人员

#### US-015: 分账报表生成
**作为** 合作伙伴
**我想要** 生成分账统计报表
**以便于** 分析分账情况和收益分布

**验收标准**:
- Given 用户有分账报表查看权限
- When 用户生成分账报表
- Then 显示分账金额、比例、订单数等指标
- Then 提供时间趋势和合作伙伴分布分析
- Then 支持按时间范围和合作伙伴筛选
- Then 报表数据导出功能完整

#### US-016: 分账数据导出
**作为** 合作伙伴
**我想要** 导出分账明细数据
**以便于** 进行离线分析和财务核对

**验收标准**:
- Given 用户有分账数据导出权限
- When 用户导出分账数据
- Then 支持Excel和CSV格式导出
- Then 导出文件包含完整的分账明细
- Then 数据格式规范且可读性强
- Then 导出操作有权限控制和审计

### 6. 权益回收池相关故事

#### US-011: 查看回收池状态
**作为** 合作伙伴
**我想要** 查看我的权益回收池状态
**以便于** 了解可用天数和回收池使用情况

**验收标准**:
- Given 用户有回收池查看权限
- When 用户访问回收池页面
- Then 显示可用天数、总计天数、已用天数
- Then 显示使用率进度条和统计信息
- Then 实时更新回收池状态

#### US-012: 权益回收审批
**作为** 系统管理员
**我想要** 审批权益回收申请
**以便于** 管理会员权益回收流程

**验收标准**:
- Given 用户有权益回收审批权限
- When 用户审批单个权益回收申请
- Then 系统验证回收限制（每个MAC最多3次）
- Then 计算实际剩余天数并入池
- Then 更新会员卡状态和回收池天数
- Then 支持批量审批功能

#### US-013: 批量兑换申请
**作为** 合作伙伴
**我想要** 申请批量兑换会员卡
**以便于** 利用回收池天数生成新的会员卡

**验收标准**:
- Given 用户有批量兑换权限
- When 用户提交批量兑换申请
- Then 系统验证回收池余额是否充足
- Then 管理员审批兑换申请
- Then 审批通过后自动生成会员卡
- Then 从回收池扣除相应天数

#### US-014: 回收池统计报表
**作为** 合作伙伴
**我想要** 查看回收池使用统计报表
**以便于** 分析回收池使用趋势和效率

**验收标准**:
- Given 用户有报表查看权限
- When 用户查看回收池统计报表
- Then 显示回收次数、兑换次数等指标
- Then 提供时间趋势图表和对比分析
- Then 支持按时间范围筛选数据

#### US-015: 回收限制管理
**作为** 系统管理员
**我想要** 管理回收限制规则
**以便于** 控制权益回收的合理性和安全性

**验收标准**:
- Given 用户有回收限制管理权限
- When 用户查看回收限制设置
- Then 显示当前回收限制规则（如MAC地址3次限制）
- Then 支持调整限制参数
- Then 限制变更需要审批流程
