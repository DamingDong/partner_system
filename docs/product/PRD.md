# 产品需求文档 (PRD) - 合作伙伴管理系统

## 📋 产品概述

### 产品愿景
构建一个简单、高效、透明的合作伙伴管理平台，为企业提供完整的合作伙伴关系管理解决方案。

### 核心价值
- **自动化管理**：减少人工操作，提高数据处理效率
- **透明化分账**：清晰的分账规则和结算流程
- **实时化监控**：实时业务数据监控和预警

### 目标用户
- **系统管理员**：系统配置和数据管理
- **合作伙伴**：业绩查看和分账管理
- **操作员**：日常运营和维护

## 🎯 功能需求

### 2.1 会员卡管理系统

#### 2.1.1 会员卡类型与状态
**会员卡类型**:
- REGULAR: 普通会员卡
- BOUND: 绑定会员卡

**会员卡状态**:
- PENDING_BIND: 待绑定状态
- BOUND: 已绑定状态
- ACTIVE: 激活状态
- EXPIRED: 已过期
- CANCELLED: 已销卡

#### 2.1.2 核心功能
- **会员卡列表**：支持搜索、筛选、分页
- **会员卡详情**：查看详细信息和管理历史
- **批量操作**：支持导入、导出、批量状态变更
- **状态管理**：激活、禁用、绑定等操作

### 2.2 订单管理系统

#### 2.2.1 订单类型定义
**订单类型**:
- **激活订单 (ACTIVATION)**：用户激活会员卡产生的订单，仅用于记录激活行为，不参与分账
- **订阅订单 (SUBSCRIPTION)**：用户续费或升级服务产生的订单，参与分账计算

**订单状态**:
- PENDING: 待处理
- PROCESSING: 处理中
- COMPLETED: 已完成
- FAILED: 失败
- CANCELLED: 已取消
- REFUNDED: 已退款

#### 2.2.2 订单管理功能
- **订单查询**：按类型、状态、时间范围筛选
- **订单详情**：查看订单完整信息
- **Excel导出**：支持导出订单数据
- **权限控制**：合作伙伴仅可查看自己相关订单

### 2.3 分账管理系统

#### 2.3.1 分账规则引擎
**分账规则类型**:
- 固定比例分账
- 阶梯式分账
- 条件式分账

**分账规则适用性**:
- 仅适用于订阅订单（SUBSCRIPTION）
- 不适用于激活订单（ACTIVATION）

#### 2.3.2 分账处理流程
1. **交易触发**：订阅订单完成时触发分账
2. **规则匹配**：根据交易信息匹配分账规则
3. **金额计算**：按照规则计算分账金额
4. **记录生成**：生成分账记录并更新账户

### 2.4 对账管理系统

#### 2.4.1 对账周期
- 日对账：每日生成对账单
- 周对账：每周生成对账单
- 月对账：每月生成对账单

#### 2.4.2 对账功能
- **自动对账**：系统按周期自动生成
- **手动对账**：支持手动触发生成
- **对账单下载**：支持PDF格式下载
- **对账状态管理**：标记已核对状态

## 🔧 技术需求

### 4.1 性能要求
- **页面加载**：首屏加载时间 ≤ 3秒
- **API响应**：接口响应时间 ≤ 2秒
- **并发支持**：支持1000+并发用户
- **数据量**：支持千万级数据存储

### 4.2 安全要求
- **数据加密**：敏感数据AES-256加密
- **权限控制**：基于角色的访问控制
- **审计日志**：完整的操作审计记录
- **传输安全**：HTTPS/TLS加密传输

### 4.3 兼容性要求
- **浏览器支持**：Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **移动端支持**：iOS 14+, Android 10+
- **分辨率支持**：320px - 2560px
