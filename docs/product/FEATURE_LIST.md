# 合作伙伴管理系统 - 功能特性列表（一期聚焦版）

## 📋 功能特性总览

### 版本规划
- **一期阶段 (v1.0)**: 聚焦渠道合作伙伴会员卡业务闭环 + 平台方基础配置管理
- **二期阶段 (v1.1)**: 权限配置灵活性和系统优化
- **三期阶段 (v1.2)**: 高级报表和数据分析

### 核心业务目标
- **渠道合作伙伴**：完成会员卡绑定、回收、兑换业务闭环，查看订单激活数量用于线下核对付款
- **平台方**：具备会员卡导入、发放等基础配置管理能力
- **权限配置灵活性**：支持渠道合作伙伴权限范围可配置

## 🎯 一期阶段 (v1.0) - 核心功能

### 1. 渠道合作伙伴功能（权限范围可配置）
**优先级**: P0 | **EPIC**: CHANNEL_PARTNER

#### 1.1 会员卡业务功能（可配置权限）
- [ ] **F001**: 会员卡绑定功能
  - 支持单个和批量MAC地址绑定
  - MAC地址格式校验和重复检查
  - 绑定操作历史记录和状态跟踪
  - **权限配置**：可配置为仅会员卡代理业务权限

- [ ] **F002**: 会员卡回收功能
  - 自有设备的权益回收申请和操作
  - 单个和批量MAC地址回收
  - 回收次数限制验证（最多3次）
  - **权限配置**：可配置为仅会员卡代理业务权限

- [ ] **F003**: 会员卡兑换功能
  - 基于自有回收池余额的兑换申请
  - 兑换数量配置和余额验证
  - 新会员卡生成和分配
  - **权限配置**：可配置为仅会员卡代理业务权限

#### 1.2 订单管理功能（可配置权限）
- [ ] **F004**: 订单激活数量查看
  - 查看权限范围内的订单激活数量统计
  - 按时间、渠道等条件筛选激活记录
  - 激活状态跟踪和异常检测
  - **权限配置**：所有渠道合作伙伴必备功能

- [ ] **F005**: 订单数据导出功能
  - Excel格式数据导出，包含卡号、激活时间等关键字段
  - 筛选条件下的数据导出权限控制
  - 导出记录和操作审计
  - **权限配置**：所有渠道合作伙伴必备功能

- [ ] **F006**: 订阅订单查询功能
  - 查看自有渠道的订阅订单（用户APK自主行为，参与分账）
  - 按时间、用户、渠道等条件筛选
  - 订单状态跟踪和分账核对
  - **权限配置**：可配置为仅订阅订单分账业务权限

### 2. 平台方功能
**优先级**: P0 | **EPIC**: PLATFORM_MANAGER

#### 2.1 基础配置管理
- [ ] **F007**: 会员卡导入功能
  - Excel模板批量导入会员卡池（支持1000张/次）
  - 会员卡数据格式校验和重复检查
  - 导入失败错误报告和重试机制

- [ ] **F008**: 会员卡库存查看功能
  - 查看所有会员卡库存状态监控和预警
  - 按渠道、状态等多维度统计
  - 库存趋势分析和关键指标展示

- [ ] **F009**: 渠道合作伙伴权限配置
  - 支持配置会员卡代理业务权限（绑定、回收、兑换）
  - 支持配置订阅订单分账业务权限（订单查询、分账查看）
  - 支持配置混合权限（同时具备两种业务权限）
  - 权限配置界面直观易用，操作日志审计

- [ ] **F010**: 会员卡发放功能
  - 支持单个和批量会员卡发放
  - 发放记录和操作历史
  - 发放数量配置和库存验证

### 3. 通用功能
**优先级**: P0 | **EPIC**: COMMON_FEATURES

#### 3.1 基础权限和系统功能
- [ ] **F011**: 用户登录和权限验证
  - 渠道合作伙伴登录并访问配置的权限功能
  - 平台方登录并访问管理功能
  - 权限验证准确，无越权访问

- [ ] **F012**: 数据权限隔离控制
  - 渠道合作伙伴只能看到权限范围内的会员卡和订单数据
  - 平台方拥有全局数据访问权限
  - 数据权限验证准确率100%

- [ ] **F013**: 信息脱敏展示
  - 用户敏感信息中间部分星号替代
  - 卡密字段脱敏展示和导出控制
  - 脱敏规则统一应用和安全审计
